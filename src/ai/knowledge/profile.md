## AI Portfolio Agent

AI Portfolio Agent is a RAG-powered conversational
assistant that allows recruiters to ask questions about
Maksym's professional experience, skills, and projects.

The backend is built using Python and FastAPI.

Professional information is stored in a knowledge base
and split into chunks.

The chunks are converted into embeddings and stored
in PostgreSQL using pgvector.

When a user asks a question, the question is converted
into an embedding and semantic vector search retrieves
the most relevant knowledge chunks.

The retrieved context is passed to an LLM to generate
a grounded response.

The project is being developed with technologies including
OpenAI API, LangGraph, RAG, embeddings, vector search,
PostgreSQL, pgvector, FastAPI, and SQLAlchemy.
